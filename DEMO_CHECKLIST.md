# 🎬 Quick Demo Video Checklist

## Before You Start (5 minutes)

### Environment Setup
- [ ] Close all unnecessary apps and browser tabs
- [ ] Clear browser bookmarks bar (looks cleaner)
- [ ] Set browser to 100% zoom
- [ ] Open Spotify desktop app (keep it visible)
- [ ] Test your webcam and lighting
- [ ] Position yourself in good lighting (face clearly visible)

### Server Setup
```bash
# Make sure server is running
npm start

# Open in browser
open http://127.0.0.1:3000
```

### Recording Tool
Pick ONE:
- [ ] **QuickTime** (Mac, built-in, easiest)
- [ ] **Loom** (Web, free, very easy) - https://loom.com
- [ ] **OBS Studio** (All platforms, professional) - https://obsproject.com

## 🎬 Recording Commands

### QuickTime (Mac)
```bash
# Open QuickTime
open -a "QuickTime Player"

# Then: File → New Screen Recording
# Click red button to start
# Click stop in menu bar when done
```

### Using Loom (Easiest)
1. Go to https://loom.com
2. Click "Start Recording"
3. Select "Screen + Camera" or "Screen Only"
4. Click "Start Recording"
5. Do your demo
6. Click "Stop" in Loom toolbar
7. Download video
