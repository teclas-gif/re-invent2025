# Vibe Coding Log

## Session 1: Inception
-   **Goal**: Detect stress and play music.
-   **Vibe**: "Frankenstein" - stitching things together.
-   **Outcome**: Created basic server with Anthropic integration.

## Session 2: Optimization
-   **Challenge**: Server latency was too high.
-   **Pivot**: Moved to client-side `face-api.js`.
-   **Result**: Real-time detection achieved.

## Session 3: Reliability
-   **Challenge**: Spotify API was flaky (auth, active device issues).
-   **Pivot**: Switched to YouTube IFrame API.
-   **Result**: "No-fail" music playback implemented.
